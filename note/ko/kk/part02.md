# 语序结构

|      |        | Example                      |
| ---- | ------ | ---------------------------- |
| 中文 | 主谓宾 | 我**吃**饭                   |
| 英文 | 主谓宾 | 我**吃**饭 I eat rice.       |
| 韩文 | 主宾谓 | 我饭**吃** 저는 밥을 먹어요. |

```markdown
저는 밥을 먹어요.
[jeo-neun bap-eul meog-eo-yo]

저 我 // 는 主语助词
밥 饭 // 을 宾语助词
먹어 吃
요 敬语句尾词尾
```

```markdown
민수는 라면 먹어요.
[min-su-neun ra-myeon meog-eo-yo]

민수 敏秀 // 는 主语助词
라면 拉面 // 零助词
먹어 吃
요 敬语句尾词尾
```

```markdown
우리는 영화를 봐요.
[u-ri-neun yeong-hwa-reul bwa-yo]

우리 我们 // 는 主语助词
영화 电影 // 를 宾语助词（元音后用 -를）
봐 看 // 보다 → 봐요（不规则变格）
요 敬语句尾词尾
```

# 语法要素

- 黏着语系
- 助词 词尾

## 助词

| 助词  | 用法          | 说明                     |
| :---- | :------------ | :----------------------- |
| 은/는 | 主语/话题助词 | 辅音后用 은，元音后用 는 |
| 을/를 | 宾语助词      | 辅音后用 을，元音后用 를 |
| 하고  | 和、与        | 连接两个名词             |
| 만    | 只、仅        | 表限定                   |

## 连接词尾

| 词尾       | 用法     | 说明                               |
| :--------- | :------- | :--------------------------------- |
| ---(으) 면 | 如果…    | 条件（辅音后用 으면，元音后用 면） |
| 아/어/여도 | 即使…也… | 让步                               |
| (으) 니까  | 因为…    | 原因（比 -(어) 서 更强调主观理由） |

## 终结词尾

| 词尾      | 用法          | 说明                  |
| :-------- | :------------ | :-------------------- |
| 습니다    | 正式敬语陈述  | 对长辈/正式场合       |
| (으) 세요 | 敬语请求/询问 | 对平辈/陌生人         |
| ㄹ/ㄹ까?  | 疑问/推测     | " 要…吗？" / " 也许…" |

# 句式语法

## (으) 세요 请...

- 动词词干 + (으) 세요
- 有收音 + 으세요
- 无收音 + 세요

```markdown
나가세요. 请出去
[na-ga-se-yo]

나가 나가다 出去 // 无收音 + 세요
요 敬语句尾词尾
```

```markdown
방을 정리하세요. 请整理房间
[bang-eul jeong-ri-ha-se-yo]

방 房间 // 을 宾语助词
정리 정리하다 整리 // 하다 + 아요 → 하세요
요 敬语句尾词尾
```

```markdown
질문을 들어 보세요. 请听题
[jeol-mun-eul deu-ro bo-se-yo]

질문 问题 // 을 宾语助词
들어 듣다 听 // 无收音 + 세요
보 보다 看 // 补助动词 表尝试
요 敬语句尾词尾
```

```markdown
빨리 오세요. 快点过来
[bbal-li o-se-yo]

빨리 快点
오 오다 来 // 无收音 + 세요
요 敬语句尾词尾
```

```markdown
조용히 하세요. 请安静点
[co-yong-hi ha-se-yo]

조용히 安静地
하 하다 做 // 하다 + 아요 → 하세요
요 敬语句尾词尾
```

```markdown
맛있게 드세요. 请好好享用
[ma-si-ge deu-se-yo]

맛있게 好吃地 맛있다 → 맛있게（-게 变副词）
드 드시다 吃 먹다 的敬语形式
요 敬语句尾词尾
```

```markdown
안녕히 주무세요. 晚安
[an-nyeong-hi ju-mu-se-yo]

안녕히 安好地
주무 주무시다 睡 자다 的敬语形式
요 敬语句尾词尾
```

```markdown
신문을 좀 읽으세요.请你看看新闻。
[xin-mun-zom il-geu-se-yo]

신문 报纸 // 을 宾语助词
좀 稍微（语气缓和）
읽으 읽다 读 // 有收音 + 으세요
요 敬语句尾词尾
```
