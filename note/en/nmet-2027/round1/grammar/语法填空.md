# 关于语法填空的考点

## 关于动词作谓语的时态语态考察

- https://www.bilibili.com/video/BV1vb421H71y?t=327.8&p=3

| 动词时态     | 使用要求                                         | 主动形式            | 被动形式                 |
| ------------ | ------------------------------------------------ | ------------------- | ------------------------ |
| **一般现在** | **不强调任何时间的动作**                         | **do / does**       | **am / is / are done**   |
| **一般过去** | **在过去发生或有结果的动作**                     | **did**             | **was / were done**      |
| 一般将来     | 在将来发生的动作                                 | will do             | will be done             |
| 现在进行     | 当前*正在*发生的动作                             | am / is / are doing | —                        |
| 过去进行     | 过去某特定时刻*正在*发生的动作                   | was / were doing    | —                        |
| 将来进行     | 将来某特定时刻*正在*发生的动作                   | will be doing       | —                        |
| **现在完成** | **过去到现在发生的动作**                         | **have / has done** | **have / has been done** |
| 过去完成     | 一句话中两个过去动作强调先后顺序，更早发生的动作 | had done            | had been done            |

```dataviewjs
const pointStyles = [
  { keyword: "动词作谓语", color: "#e03131", background: "#ffe3e3" },
  { keyword: "动词作非谓语", color: "#e0a000", background: "#fff3bf" },
  { keyword: "无提示词后面是句子", color: "#2b8a3e", background: "#ebfbee" },
];

function getStyle(title) {
  const match = pointStyles.find((p) => title.includes(p.keyword));
  if (!match) {
    return "";
  }

  return `
    color: ${match.color};
    background: ${match.background};
    padding: 2px 6px;
    border-radius: 4px;
  `;
}

const pages = dv
  .pages('"note/en/nmet-2027/round1/grammar/practice"')
  .where((p) => p.file.name.includes("grammar-practice-"))
  .sort((p) => p.file.name);

const columns = Array.from({ length: 10 }, (_, i) => String(i + 1));

const rows = [];

for (const page of pages) {
  const content = await dv.io.load(page.file.path);
  const h2s = [...content.matchAll(/^##\s+(\d+)\s+(.+)$/gm)];

  const headings = Object.fromEntries(
    h2s.map(([, number, title]) => [
      number,
      { title, fullTitle: `${number} ${title}` },
    ]),
  );

  const row = [
    page.file.link,

    ...columns.map((_, i) => {
      const heading = headings[String(i + 11)];
      if (!heading) return "";

      const link = dv.el("span");
      link.style.cssText = getStyle(heading.title);

      const target = `${page.file.path}#${heading.fullTitle}`;
      const a = link.createEl("a", { text: heading.title });
      a.addClass("internal-link");
      a.dataset.href = target;
      a.href = target;

      return link;
    }),
  ];

  rows.push(row);
}

dv.table(["Practice", ...columns], rows);
```
