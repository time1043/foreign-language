## 关于动词作谓语的时态语态考察

- https://www.bilibili.com/video/BV1vb421H71y?t=327.8&p=3

| 动词时态     | 使用要求                                         | 主动形式            | 被动形式                 |
| ------------ | ------------------------------------------------ | ------------------- | ------------------------ |
| **一般现在** | **不强调任何时间的动作**                         | **do / does**       | **am / is / are done**   |
| **一般过去** | **在过去发生或有结果的动作**                     | **did**             | **was / were done**      |
| 一般将来     | 在将来发生的动作                                 | will do             | will be done             |
| 现在进行     | 当前*正在*发生的动作                             | am / is / are doing | —                        |
| 过去进行     | 过去某特定时刻*正在*发生的动作                   | was / were doing    | —                        |
| 将来进行     | 将来某特定时刻*正在*发生的动作                   | will be doing       | —                        |
| **现在完成** | **过去到现在发生的动作**                         | **have / has done** | **have / has been done** |
| 过去完成     | 一句话中两个过去动作强调先后顺序，更早发生的动作 | had done            | had been done            |

| you  | you      | **yourself**     | **your**          | yours                  |
| he   | **him**  | **himself**      | **his**           | his                    |
| she  | **her**  | **herself**      | **her**           | hers                   |
| it   | it       | **itself**       | **its**           | its                    |

| we   | **us**   | **ourselves**    | **our**           | ours                   |
