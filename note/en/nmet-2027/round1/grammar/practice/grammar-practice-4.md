## 11 动词作谓语——时态/语态/主语

```markdown
Edward O. Wilson, the "modern-day Charles Darwin", **damaged** his right eye
==when== he **was catching** a fish _in the river_ _near his home_ _at seven_.

谓语
过去、主动、单数

一般过去 caught
过去进行 突发动作 was catching ✅
过去完成 had caught 🙅 // 有两个过去 但没强调先后

核心词汇
catch - caught - caught - catching
```

```markdown
**动作先后顺序**：一个动作完成，另一个动作开始，不同时发生
v1 -- // 写完作业
v2 ------ // 出去玩（出去玩的时候，已经写完作业了）

🙅 有交集，不满足“动作先后顺序”
v1 ------
v2 ------
```

```markdown
突发动作
一般过去（突发） + when + 过去进行（过程）

我在街上走（过程）
我遇到了同学（突发）
I **met** my classmate ==when== I **was walking** in the street.

// 写作
suddenly
```

## 12 名词复数变化

```markdown
The poor eyesight only **allowed** him _to observe_ small _creatures_, like ants.

提示词为名词：考察复数变化、词性转换

名词
1 词性变化 creature - create // 尽量避免由繁入简
2 名词复数变化

核心词汇
create v 创造
creative adj 有创造力的、有创意的
creativity n 创造力、创意（能力）
creation n 创造（事件/结果）
creature n 生物 // 造物主创造出的
```

## 13 动词作非谓语——主动被动

```markdown
Interested _in the selflessness_ _of ants_, // 非谓语 不管
==which== **would sacrifice** themselves _for their colony (群体)_, // 从句 不管
Wilson **developed** a theory,
_confirming_ the existence _of altruistic (利他的) behavior_ _in a wide range_ _of species_.

核心词汇
confirm v 确认（把不确定变成确定）
confirmation n 确认

非谓语
主动 // 后面有名词
to do 🙅
doing ✅

在逗号的后面，非谓语主动不使用to do，有插入语除外
_To do sth_, sb do sth “为了做某事，某人做了某事”
Sb do sth _to do sth_ “某人做某事为了做某事”
Sb do sth(, ...,) _to do sth_

I asked his to look for the book.
I asked his, one of my students, to look for the book.
```

## 14 动词作谓语——时态/语态/主语

```markdown
The evidence _of existing studies_ **suggests**
==that== there **may be** a connection.

谓语
现在（一般现在）、主动（后宾语从句）、单数

核心词汇
sb suggest v 建议 // advice / recommend
sth suggest v 表明 // show
```

## 15 形容词副词——比较级最高级

```markdown
It **appears**
==that== more grateful people report _sleeping_ _better_ and _feeling_ _healthier_.

and并列

// 说简单不简单，说复杂不复杂，英语早就为你考虑过了，都可以接受
healthy - healthier - healthiest ✅ 简单
healthy - more healthy - most healthy ✅ 复杂
```

## 16 无提示词后面是句子：从句引导词

```markdown
Now researchers **still need** _to make_ it clear
==why== gratitude **is** so good _for our health_.

形式宾语it，视作不存在

// 判断句子完整性（缺不缺名词）
主x从v 宾语从句
how 如何, why 为什么, whether 是否

// 上下文
前文：他好、他怎么好
现在：他为什么好
```

```
判断句子完整性的特殊情况——不知道
I have no idea / clues / understanding
I am not sure
= I don't know 不完整

I have no idea ________ the machine works. 主x从v
I have no idea ____how____ the machine works.
I have no idea ____why____ the machine works.
I have no idea ____whether____ the machine works.
```

## 17 无提示词后面是句子：从句引导词

```markdown
_During the class_, the crew **showed** the students a science glove-box,
==where== the plants experiments **are performed**.

show sb sth 向某人展示某物（双宾语动词）
从句被动语态 完整句

主v从v 状语从句/定语从句
where, when; why, that; conj
主从句都完整，当从句关系词都不成立时，再考虑逻辑连词 // because, so, but ...

where 位置关系 “在那里” ✅ “植物实验被开展｜在这个盒子里”
when 事件关系 “在那时”
why 因果关系 // reason why
that 总分关系 // 同位语从句 对前面抽象名词作解释 由概括到具体
```

- 需要看的是句子的构造/成分分析/完整性

## 18 无提示词后面是短语：介词

```markdown
Then, the astronauts **had** real-time interactions _with students_ through video calls
==and== they **answered** students' questions like

and并列句子

“视频通话是他们实时交互的手段”
描述方式和手段的介词 “通过...”
through + sb/sth “通过某人/某物” // through video calls
by + doing sth “通过某个动作” // by making video calls
```

## 19 动词作谓语——时态/语态/主语

```markdown
"What kinds of plants **will be brought** _to space_ _in future spaceflights_?"

谓语：将来、被动、复数
bring sth // 如果动词后面应该有名词，但是句中没有，那么该动词很可能是被动

核心词汇
bring - brought - brought - bringing
```

## 20 动词作谓语——时态/语态/主语

```markdown
_At the end of the class_, the crew **said**,
"We **expect**
you guys _to build_ our space home better _in the future_. "

一句话存在谓语，空格需要非谓语
主动/目的/预期结果

expect sb to do sth
```

```markdown
// 存在歧义
"We **expect** (that)
you guys **will build** our space home better _in the future_. "

将来、主动、复数
// 一般将来时得多重要，才能在一套题目考两次？
// 谓语考点重在在一般现在、一般过去、现在完成
```
