## 11 动词作谓语——判断时态/语态/主语单复数

```markdown
_Over the past thirty years_, there **have been** many studies _showing_

时间：从过去到现在/现在完成 // 显眼的标志，没有就别考虑
语态：主动
主语：复数 many studies

// 时间标志（从过去到现在 现在完成）
over / in + past ... “在过去的...时间里”（从现在倒推）
since + 过去时间 “自从过去某时到现在”
by now “过去到现在为止” up to now, till now
recently “最近”

使用现在完成时，句中必然有表示过去到现在的特殊时间标志
```

## 12 动词作非谓语——主动被动

```markdown
==that== writing a gratitude letter _to another person_ **offers** us an opportunity _to escape_ _from negative emotions_.

// 非谓语 -> 主动 -> 目的/预期
主动：to do、doing
被动：done 🙅

doing 同时发生 “一边...一边...”（后面出现的是**同步动作**）
to do 目的 “为了...”（后面出现的是**期待的结果**） ✅

escape后面不应该有名词
如果动词后面不需要有名词，该动作一定为主动

“我打他”
“他被我打” // 被动就是 把动词后面的名词 挪到主语的位置

“我逃跑” // 动词后面没有名词可以挪
```

## 13 形容词副词——比较级最高级

```markdown
==Even if== we **don't share** our writing _with anyone_,
the act of completing the exercise alone **makes** us happier ==and== _more satisfied_ with life.

and并列短语（and后面是短语）
and并列 "happier" "more satisfied"

比较级：比较**双方**差异、体现前后变化
最高级：在比较范围**多方**中最特别的

// 暂时忽略语法名词：单音节双音节多音节 音节音标重音
长得很简单的形容词副词：比较级“+er”；最高级“+est”
长得很复杂的形容词副词：比较级“more + 原形”；最高级“the most + 原形”
绝对不存在“more +er”，只能二选一
```

# 思路总结

- https://www.bilibili.com/video/BV1vb421H71y?t=82.1&p=3

## 解题思路

- 提示词是动词时，主要考查谓语、非谓语、词性变换。
- 如果动词后面不需要接名词，该动作一定为主动。
- 使用现在完成时，句中必然有表示“从过去到现在”的特殊时间标志。
- 使用过去完成时，要求同一句话里有两个过去动作，并强调先后顺序。

## 语法知识

- time 后面的从句往往省略关系词。
- 表示“是否”只用 whether，if 只用于表示“如果”。
- when / while / before / after / though / if 如果后面没有主语，直接出现动词，该动词使用非谓语形式。
- 可以加 -er / -est，也可以用 more / most + 原形，绝对没有 more + 比较级（如 more better）这种形式。

# 考点总结

## 无提示词空格后面是短语——冠词、介词

- 冠词判断空格后面名词是否是独一无二的；
- 介词重点积累常见用法

## 无提示词空格后面是句子——从句关系词、连词

- 观察前后两句话是否完整，是否缺少名词
- 主句不完整、从句完整：how / why / whether
- 主句完整、从句不完整：从句缺人 that / who；缺物 that / which

## 动词作谓语——判断时态语态

- 过去现在将来、主动被动、主语单复数

## 动词作非谓语——判断主动或被动

- 主动：doing 同时发生动作、to do 目的预期结果；
- 被动：done

## 形容词副词的比较级和最高级

- 简单词：+er / +est；
- 复杂词：more / most + 原形

## 词性变换——动名形副之间转换

- 词汇积累
