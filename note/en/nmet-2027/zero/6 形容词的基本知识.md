# 什么是形容词 What Is an Adjective?

- 形容词是给出**人物、事物或地点**相关信息的词（为名词服务）

| 形容词类型     | 例词                                                         | 例句                                                                    |
| :------------- | :----------------------------------------------------------- | :---------------------------------------------------------------------- |
| **描述形容词** | black, happy, bad, big, hot, difficult, pretty, empty, ready | _Black_ clouds mean _bad_ weather. <br>Learning English is _difficult_. |
| ~~物主形容词~~ | my, your, his, her, its, our, their                          | _My_ car is next to _your_ house.                                       |
| ~~指示形容词~~ | this, that, these, those, such                               | _Those_ students need _these_ pens.                                     |
| ~~数词量词~~   | some, many, every, six, ten                                  | _Many_ students have _three_ classes.                                   |
| **名词**       | 所有名词                                                     | My _math_ class is difficult. <br>Mr. Miller works in a _pet_ store.    |

# 描述形容词

## 1、描述形容词的基本用法

- 描述形容词用于描述名词
- 可以放在**名词前面**，或放在 **be 动词后面**

```markdown
We have a _new_ clock.
The clock is _new_.
```

- 描述形容词不受名词单复数影响

```markdown
We have a _new_ clock.
We have two _new_ clocks.
```

### 常见错误

```markdown
I have a car red.
She has ten reds apples.
```

```markdown
I have a _red_ car. 形容词位置错误
She has ten _red_ apples. 形容词没有单复数
```

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=648.0&p=6
- 给形容词加复数这种错误貌似没人犯，中文的语言习惯没有复数变化

## 3、描述形容词变成副词（重要考点）

### 基本变化：在形容词末尾加 `-ly`

| 形容词  | 副词      |
| :------ | :-------- |
| careful | carefully |
| clear   | clearly   |
| current | currently |
| sad     | sadly     |
| quick   | quickly   |
| quiet   | quietly   |
| slow    | slowly    |
| sudden  | suddenly  |

### 以 `y` 结尾且读音为 /i/ 的形容词，去 `y` 改 `i` 再加 `-ly`

| 形容词 | 副词    |
| :----- | :------ |
| happy  | happily |
| angry  | angrily |
| easy   | easily  |
| heavy  | heavily |
| busy   | busily  |
| noisy  | noisily |

### 以 `y` 结尾且读音为 /ai/ 的形容词，直接加 `-ly`

| 形容词 | 副词  |
| :----- | :---- |
| dry    | dryly |
| shy    | shyly |

### 以 `ic` 结尾的词，加 `-ally`（public 例外）

| 形容词     | 副词           |
| :--------- | :------------- |
| _specific_ | _specifically_ |
| _basic_    | _basically_    |
| automatic  | automatically  |
| economic   | economically   |
| scientific | scientifically |
| energetic  | energetically  |
| classic    | classically    |
| **public** | **publicly**   |

# 物主形容词

- 物主形容词体现 某人拥有某物

| 主语 | 物主形容词 | 例句                                              |
| :--- | :--------- | :------------------------------------------------ |
| I    | my         | I have a book. _My_ book is interesting.          |
| you  | your       | You have a car. _Your_ car is white.              |
| he   | his        | He has a watch. _His_ watch is gold.              |
| she  | her        | She has a watch. _Her_ watch is silver.           |
| it   | its        | It has a leg. _Its_ leg is short.                 |
| we   | our        | We have books. _Our_ books are heavy.             |
| they | their      | They have watches. _Their_ watches are expensive. |

## 常见错误

```markdown
Mary has his doctor appointment today.
They have theirs laptops.
I do not have me book.
```

```markdown
Mary has _her_ doctor appointment today. 性别错误
They have _their_ laptops. 形式错误 形容词
I do not have _my_ book. 形式错误 形容词
```

# 指向形容词

- 指向形容词用于指出特定的名词
- 指向形容词有单复数变化

|              | 单数                     | 复数                        |
| ------------ | :----------------------- | :-------------------------- |
| 距离说话者近 | _This_ passport is blue. | _These_ passports are blue. |
| 距离说话者远 | _That_ passport is red.  | _Those_ passports are red.  |

## 常见错误

```markdown
These lesson is simple.
Are very good these books.
```

```markdown
_This_ lesson **is** simple. 单复数错误
_These_ books **are** very good. 语序错误
```

## 练习：选择正确的指向形容词

```markdown
I can't answer (this / these) exam questions.
(That / Those) glass is empty.
Who is (this / that) man over there?
(This / These) students are from Colombia.
Can you help me with (this / these) question?
(This / These) map is the best for your class.
The teacher can explain (that / those) grammar lesson again.
(That / Those) eggs are for your lunch tomorrow.
```

```markdown
I can't answer _these_ exam questions.
_That_ glass is empty.
Who is _that_ man over there? 那边
_These_ students are from Colombia.
Can you help me with _this_ question?
_This_ map is the best for your class.
The teacher can explain _that_ grammar lesson again.
_Those_ eggs are for your lunch tomorrow.
```

# 名词作形容词

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=4837.3&p=6

- 只要是名词都可以作形容词，在某些情况下
- 使用名词作形容词时，第一个名词描述第二个名词
- 名词作形容词时**必须为单数**

```markdown
名词作形容词
my _Tuesday_ class = my class on Tuesday 介词短语
a _math_ test = a test about math 介词短语
a _shoe_ store = a store that sells shoes 定语从句
```

- 为了描述名词（同一件事）

1. 名词作形容词（简化 语言从简）
2. 介词短语
3. 定语从句（复杂）
