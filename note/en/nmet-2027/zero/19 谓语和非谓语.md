# 什么是谓语 What is Predicate?

- 谓语描述句子**主语**的**动作或状态特征**
- 谓语指明主语“做什么”、“是什么”或“是什么样的”
- 谓语可以是 _单独动词的时态变化_，也可以是 _动词加形容词_，可以是 _情态动词加动词_
- 谓语有**主动和被动**两种不同的形态

```markdown
I **made** your birthday cake last night.
Your birthday cake **was made** by me last night. 被动

This book **is** my gift for you.
I **felt tired** after a day's work.
My pen **is in my bag**.

I **can finish** the task on my own.
This city **was built** in Tang Dynasty to defend people. 被动
```

## 被动语态

- 在被动语态的语句中，**动作的宾语**处于**主语的位置**
- 没有宾语的动词（不及物动词）不存在被动语态

```markdown
The doctor **examined** _the child_. 主动
_The child_ **was examined** (by the doctor). 被动
```

### 重要考点：被动语态的变化

- 动词变为 be 动词 + 过去分词（do 变为 be+done）

| 时态         | 主动                | 被动                                               | 例句                                                                                                                                              |
| ------------ | :------------------ | :------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------ |
| 一般现在     | do / does           | am/is/are + done<br>am/is/are _not_ + done         | New cars **are tested** before they **are delivered** to the market. <br>New cars **are not delivered** to the market before they **are tested**. |
| 一般过去     | did                 | was/were + done<br>was/were _not_ + done           | A new species of wild tomato **was discovered** _recently_. <br>Tomatoes **were not grown** in England until the _late 16th century_.             |
| 一般将来     | will do             | will be + done<br>will _not_ be + done             | The job **will be finished** _today_. <br>The book **will not be returned** _tomorrow_.                                                           |
| 现在完成     | have/has done       | have/has been + done<br>have/has _not_ been + done | Drones **have been used** by the American military _since 1919_. <br>An accurate way to predict earthquakes **has not been found**.               |
| 过去完成     | had done            | had been + done<br>had _not_ been + done           | When they came to the scene, the window **had been broken**.                                                                                      |
| ~~现在进行~~ | ~~am/is/are doing~~ | ~~am/is/are being + done~~                         | ~~—~~                                                                                                                                             |
| ~~过去进行~~ | ~~was/were doing~~  | ~~was/were being + done~~                          | ~~—~~                                                                                                                                             |

# 什么是非谓语 What is Non-Predicate?

- 在句子不是谓语的动词，都是非谓语动词
- 谓语体现动作时间，非谓语**与时间没有关系**
- 谓语受人称和单复数限制，非谓语**完全不受影响**
- 非谓语动词也要**为名词服务**，非谓语动词也有**主被动**

```markdown
Last week, Miss Mary **came** to our classroom.
Last week, Miss Mary **came** to our classroom _to have_ a talk with us.

Larry **likes** the pop music.
Larry **has** nothing _to do_ today.
```

## 重要考点：非谓语动词的基本形态

| 种类     | 形式  | 作用                                     |
| :------- | :---- | :--------------------------------------- |
| 动名词   | doing | 句子主语、动词宾语、介词宾语             |
| 不定式   | to do | 动词宾语、补充名词、补充形容词、目的副词 |
| 现在分词 | doing | 形容词、副词                             |
| 过去分词 | done  | 形容词、副词                             |

```markdown
_Running_ **is** healthy. 动名词/名词
The girl _sitting_ these **is** my friend. 现在分词/为名词服务
```

```markdown
_Finally_, we **arrived** at the city.
```

- It is necessary _not to sleep_ at night.
- I am glad _to see_ you.
- I am glad _seeing_ you. // doing 唯独没有补充形容词的作用

- 用这么多句子，洗掉关于“非谓语”过去错误的认知，功能非常地简单直接
- “非谓语”不能做动词，那就充当其他词性，名词、形容词、副词；但是不能充当介词、连词（虚词）
- 回到第一节课，自洽闭环
- 用语法书学英语的最大的问题就在于，每一块都是割裂的/不联系/没关联

```markdown
The girl _sitting there_ **is** my friend. 形容词 现在分词 “坐在那的女孩”
The girl ==who== is sitting there **is** my friend. 形容词从句 “正坐在那的女孩”
```
