# 关于英语的时态

- 时/时间：过去、现在、将来、过去将来
- 态/状态：一般、进行、完成、完成进行

## 关于英语里的时间概念

![[time|500]]

- 广义现在：任何时间
- 狭义现在：当前这一刻，当前的一瞬间
- 过去：现在之前，与现在完全没有关系的时间
- 将来：现在之后，还没有到来的时间

# 一般过去时（高考最重要的时态）

- 在过去发生的动作 actions that happen in the past
- 句子的动词体现动作时间

## 常见的过去时间

- yesterday

```markdown
We **played** soccer _yesterday_.
```

- last+ 时间词
- last night, last week, last month...

```markdown
I **finished** my homework early _last night_.
```

- 数字 + 时间 +ago（以前）
- two hours ago, three days ago, four weeks ago...

```markdown
She **arrived** here _two weeks ago_.
```

- 注意：如果时间短语放在句首，需要用逗号隔开

```markdown
_Yesterday_, we played soccer.
_Last night_, I finished my homework early.
_Two weeks ago_, she arrived here.
```

## 一般过去的否定表述

- 一般过去时变否定，加入**助动词 did not**
- 原来的动词使用原形 do

| 主语            | 否定形态       | 例句                           |
| :-------------- | :------------- | :----------------------------- |
| I               | did not like   | the dessert at the restaurant. |
| He / She / It   | did not arrive | on time.                       |
| You / We / They | did not have   | homework yesterday.            |

- did not 可以缩写为 didn't
- 不建议在写作里使用

### 常见错误

```markdown
Andrea no lived in Korea in 2011.
We do not arrive late.
I did not took the bus yesterday.
Norah was not wake up at 7 this morning.
```

```markdown
Andrea **did not live** in Korea _in 2011_. // 未使用助动词
```

## 使用 `be going to` 表达将来

## 使用 `will` 表示将来

- 现在作出的未来的计划或决定 future plans/decisions
- 语气较强的预测 strong prediction
- 承诺或提供帮助 promises or offering help

| 主语            | 肯定 | 否定     | 其它信息                      |
| :-------------- | :--- | :------- | :---------------------------- |
| I               | will | will not | answer the door               |
| He / She / It   |      |          | have a great time on vacation |
| You / We / They |      |          | read this book                |
|                 |      |          | drive to work in the snow     |
|                 |      |          | watch that boring movie       |
|                 |      |          | be late this time             |

### `will` 的缩写形式

| 肯定                | 否定                 |
| :------------------ | :------------------- |
| I will = I'll       | will not = **won't** |
| he will = he'll     |                      |
| she will = she'll   |                      |
| it will = it'll     |                      |
| we will = we'll     |                      |
| you will = you'll   |                      |
| they will = they'll |                      |

- 在写作中尽量避免使用缩写形式

## 常见的未来时间

| 时间短语                      | 介词短语                       |
| :---------------------------- | :----------------------------- |
| next Saturday/week/month/year | in a day/week/month/year       |
| next time                     | in five minutes / in two hours |
| later                         | on the weekend / my birthday   |
| tomorrow                      | by 2030                        |

- 如果时间短语放在句首，需要逗号断开

```markdown
We **are going to go** to the movies _on Saturday_.
_On Saturday_, we **are going to go** to the movies.

The airline **will use** a new kind of jet _next year_.
_Next year_, the airline **will use** a new kind of jet.
```
