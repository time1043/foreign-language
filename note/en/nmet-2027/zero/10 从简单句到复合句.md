# 什么是简单句 What is a Simple Sentence?

- 英语句子的基本要求：一组词，有完整意思，有主语，有动词，大写字母开头，句号/问号/叹号结尾

- 简单句就是有一套 **“主语 + 动词结构”** 的句子
- 主语可以不止一个，动词也可以不止一个
- 但是 “主语 + 动词结构” 只能有一套

| 简单句类型          | 主语                | 动词和其它信息                            |
| :------------------ | :------------------ | :---------------------------------------- |
| 1 个主语 + 1 个动词 | Japan               | **imports** oil.                          |
| 1 个主语 + 2 个动词 | Japan               | **imports** oil ==and== exports vehicles. |
| 2 个主语 + 1 个动词 | Japan ==and== China | **import** oil.                           |
| 2 个主语 + 2 个动词 | Japan ==and== China | **import** oil ==and== export vehicles.   |

## 简单句的格式

### 1、陈述

| 简单句类型               | 例句                                      |
| :----------------------- | :---------------------------------------- |
| 主语 + 动词（+ 宾语）    | An earthquake **hit** Sichuan.            |
| 介词短语 + 主语 + 动词   | _In 2008_, an earthquake **hit** Sichuan. |
| 主语 +be 动词 + 形容词   | German and English **are** similar.       |
| 主语 +be 动词 + 介词短语 | Germany **is** _in Europe_.               |

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=537.1&p=10
- 谨慎使用这样的术语：主谓宾，主谓双宾，主系表，主系状
- 宾语是最没地位的，客随主便，不能决定动词时态，不能决定动词的单复数，不能决定句子中的任何

### 2、命令和请求（祈使句）

| 简单句类型                                         | 例句                                                                         |
| :------------------------------------------------- | :--------------------------------------------------------------------------- |
| 动词原形（+ 宾语 + 介词短语）<br>主语 you 被省略了 | **Consider** the cost of travel.<br>Please **make** your decision carefully. |

### 3、疑问

| 简单句类型                        | 例句                                         |
| :-------------------------------- | :------------------------------------------- |
| 助动词 + 主语 + 动词原形          | **Do** you **run** in the morning?           |
| 疑问词 + 助动词 + 主语 + 动词原形 | How **do** you **choose** the running route? |
| be 动词 + 主语 + 形容词           | **Is** the running necessary?                |
| 疑问词 +be 动词 + 主语            | What **are** the benefits?                   |

```markdown
The running **is** necessary. 肯定句
**Is** the running necessary? 疑问句
```

## 简单句的功能

### 1、陈述信息——简单句最常见的应用

```markdown
Barack Obama **became** president in 2009.
This paper **will discuss** the economic situation in Argentina.
```

### 2、发出命令、提出请求——用于指挥读者的行为

```markdown
**Note** the difference between these two types of animals.
**Let** us now turn our attention to the third category.
```

### 3、提出问题——引起读者关注，引发读者思考

```markdown
How **does** aspirin **work**? This question has puzzled scientists for centuries. 引出文章主题
=> How does aspirin work?

**Will** this new plan really **solve** the problem? Only time will tell. 引出作者态度（不知道，客观看待）
**Will** this new plan really **solve** the problem? You will not be disappointed. 引出作者态度（能够解决）
```

# 什么是复合句 What is a Compound Sentence?

- 使用**基本连词**把**两个简单句连在一起**变成更长的句子，称为**复合句**
- 复合句有两套或更多的 **“主语 + 动词结构 ”**

- 复合句连词 FANBOYS：for, and, nor, but, or, yet, so
- 复合句中两个简单句简单句对等

| 简单句 1              | 基本连词 | 简单句 2                        |      |
| :-------------------- | :------- | :------------------------------ | ---- |
| Japan **imports** oil | ,==and== | China **imports** gas.          | 并列 |
| Japan **imports** oil | ,==but== | Saudi Arabia **exports** it.    | 相反 |
| Japan **imports** oil | ,==so==  | oil price in Japan **is** high. | 因果 |

- 注意：基本连词前面需要用**逗号**断开，不要用基本连词连接两个独立句

```markdown
Japan imports oil ==and== China imports gas. 🙅
Japan imports oil, ==and== China imports gas. ✅

Japan imports oil. ==But== Saudi Arabia exports it. 🙅
Japan imports oil, ==but== Saudi Arabia exports it. ✅
```

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=5142.5&p=10
- 前一句的宾语 和 后一句的主语 用 and 并列，没有逗号隔开，容易混乱引起歧义

## 基本连词的作用

- **and** 补充额外信息 extra information
- **but** 补充相反或对立的信息 opposite information
- **so** 表示结果或目的 result / purpose

```markdown
I am 17 years old, ==but== he is 18 years old. 🙅 并非相反（中文的翻译陷阱）
I am 17 years old, ==and== he is 18 years old. ✅ 并列
```

### 常见错误

```markdown
Five is an odd number but six is an even number.
I like tea, so I drink coffee sometimes.
Costa Rica is in Central America. And Peru is in South America.
July is usually a month with a great deal of rainfall, this year it has been very dry.
```

```markdown
Five is an odd number, ==but== six is an even number. 基本连词前面无逗号
I like tea, ==but== I drink coffee sometimes. 基本连词使用错误
Costa Rica is in Central America, ==and== Peru is in South America. 基本连词不连接两个独立句
July is usually a month with a great deal of rainfall, ==but== this year it has been very dry. 两个句子不能逗号连接
```

## 基本连词的具体用法

### 1、and 的用法

- 两分句逗号断开、两词不需要逗号、三者列举需要逗号

```markdown
China is in Asia, ==and== it has a large population.
China **is** in Asia and **has** a large population.
_China and Japan_ **are** in Asia.
_China, Korea, and Japan_ **are** in Asia.
```

### 2、but 的用法

- 两分句逗号断开，两词不需要逗号

```markdown
Shanghai is a large city, ==but== it is not China's capital.
The weather in January **is** _sunny but cold_.
I **feel** _nervous but excited_.
```

- A 和 B 一致 and
- A 和 B 相反 but

### 3、so 的用法

- 表示结果，“所以：”需要逗号断开
- 表示目的，“为了/这样才能：”不需要逗号断开

```markdown
I study hard, ==so== I have a good grade in the exam.
I study hard ==so / so that== I can have a bright future.
```
