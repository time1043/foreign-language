# 什么是复杂句 What is a complex sentence?

- 复杂句是另一种更长的句子
- 复杂句由主句和从句构成，复杂句：主句从句地位不等
- 主句和从句都有自己的 "主语+动词结构"
- 主句可以自己独立存在，从句不能自己独立存在

# 常用的复杂句连接词

- because, after, before, when, as soon as, if

| 复杂句                       | 主句                     | 从句                       |
| :--------------------------- | :----------------------- | :------------------------- |
| I failed the test because I did not study. | I failed the test | because I did not study |
| Joe watches TV after he finishes dinner. | Joe watches TV | after he finishes dinner |
| Many tourists change money before they travel to another country. | Many tourists change money | before they travel to another country |
| People should be careful when they use a knife. | People should be careful | when they use a knife |
| We walk to class if the weather is nice. | We walk to class | if the weather is nice |

## 练习：区分主句和从句，标出连接词

```markdown
1. I want to bake a cake for Lim because tomorrow is his birthday.
2. I want to make a chocolate cake because chocolate is his favorite cake.
3. I need to go to the store before I can make Lim's cake.
4. I have to buy a lot of flour and sugar if I want to make a very big cake.
5. I can put frosting on the cake after it cools down.
6. Lim will be so happy when he sees his birthday cake.
7. My brother bought 26 candles because Lim will be 26 years old.
8. My brother will put the candles on the cake when it is ready.
9. Lim's sister will sing "Happy Birthday" because she has a great voice.
10. Everyone will be happy if Lim is happy.
```

# 复杂句的语序

- 一般情况下，主句在前，从句在后，连接词在从句开头，**绝对不需要逗号断开**

```markdown
John is hungry now because he did not eat lunch.
```

- 从句也可以放在前面，**一定要用逗号与主句断开**

```markdown
Because John did not eat lunch, he is hungry now.

When I saw him, I was very happy. = I was very happy when I saw him.
```

- 如果句子里有名词和代词，则名词先出现，代词后出现，不管前面的是主句还是从句

```markdown
John is hungry now because he did not eat lunch.
Because John did not eat lunch, he is hungry now.
```

## 注意：常见错误

**从句不能自己独立成句**

```markdown
Because the weather is cold. You need a sweater.
→ Because the weather is cold, you need a sweater.
```

**主句在前不需要逗号断开**

```markdown
You need a sweater, because the weather is cold.
→ You need a sweater because the weather is cold.
```

**从句在前需要逗号断开**

```markdown
Because the weather is cold you need a sweater.
→ Because the weather is cold, you need a sweater.
```

**连接两句话用一个连接词就够了**

```markdown
Because the weather is cold, so you need a sweater.
→ Because the weather is cold, you need a sweater.
```

# 使用 because 表示原因

- 以 because 开始的从句叫原因从句
- 原因从句里的动词可以是过去、现在或将来

| 主句                     | 原因从句                             | 时间   |
| :----------------------- | :----------------------------------- | :----- |
| I study every night      | because I want to get good grades.   | 现在   |
| I failed the math test   | because I did not understand the lesson. | 过去 |
| I will study tonight     | because we are going to have a test tomorrow. | 将来 |

**原因从句放在句首，要用逗号和主句断开**

```markdown
Because the car was expensive, Pablo did not buy it.
Pablo did not buy the car because it was expensive.
```

## 练习：使用原因从句改写句子

```markdown
1. My sister will study tonight. She has a test tomorrow.
   My sister will study tonight because she has a test tomorrow.
2. You need an umbrella. It is raining now.
   Because it is raining now, you need an umbrella.
3. The class understood the professor easily. She spoke clearly.
   The class understood the professor easily because she spoke clearly.
   Because the professor spoke clearly, the class understood her easily.
4. I am going to take my car to the repair shop. It is making a noise.
   Because my car is making a noise, I am going to take it to the repair shop.
```

# 使用 after, before, when 和 as soon as 表示时间

- after, before, when 和 as soon as 表示从句和主句的时间关系

| 时间关系     | 含义           |
| :----------- | :------------- |
| after        | 在……以后       |
| before       | 在……之前       |
| when         | 在……时         |
| as soon as   | 一……就……       |

- 以 after, before, when 和 as soon as 开始的从句叫时间从句

| 主句                     | 时间从句                 | 时间关系              |
| :----------------------- | :----------------------- | :-------------------- |
| Leila drove to work      | after she had coffee.    | after=第一个动作      |
| Josh called his friend   | before he left.          | before=第二个动作     |
| My sister took a nap     | when she got home.       | when=第一个动作       |
| The group toured the city | as soon as they arrived in Beijing. | as soon as+第一个动作 |

**时间从句放在句首，要用逗号和主句断开**

```markdown
Before Omar went to the airport, he packed his suitcase.
Omar packed his suitcase before he went to the airport.
```

## 练习：使用时间从句改写句子

```markdown
1. I heard your good news. I was so happy. (when)
   When I heard your good news, I was so happy.
2. You should read the bill carefully. You pay the bill. (before)
   You should read the bill carefully before you pay it.
3. We went to sleep. We watched that long movie. (after)
   After we watched that long movie, we went to sleep.
4. I ate lunch. I washed my dish and put it in the cabinet. (after)
   After I ate lunch, I washed my dish and put it in the cabinet.
5. Natalia went to England. Natalia did not speak any English. (before)
   Before Natalia went to England, she did not speak any English.
6. My sister decided to buy those shoes. My sister saw the low price. (when)
   My sister decided to buy those shoes when she saw the low price.
7. I graduated from high school. I got a summer job. (as soon as)
   As soon as I graduated from high school, I got a summer job.
```

# 使用 if 表示条件

- if 开始的从句用于给出主句的条件
- 以 if 开始的从句叫条件从句

| 主句                     | 条件从句                             |
| :----------------------- | :----------------------------------- |
| You cannot check your email in this room | if the Internet does not work here. |
| You need six or more eggs | if you want to make a big cake. |
| The passengers will miss their second flight | if their first flight arrives late. |

**条件从句放在句首，要用逗号和主句断开**

```markdown
If we have extra time, we want to play basketball.
We want to play basketball if we have extra time.
```

## 练习：使用条件从句改写句子

```markdown
1. You read this book. You will laugh a lot.
   If you read this book, you will laugh a lot.
2. The lake will freeze tonight. The weather is really cold.
   The lake will freeze tonight if the weather is really cold.
3. You need to buy a new computer. Your computer is broken.
   If your computer is broken, you need to buy a new one.
4. Sarah travels to China in November. The ticket will be expensive.
   If Sarah travels to China in November, the ticket will be expensive.
5. I do not know the meaning of a word. I look up the meaning in a dictionary.
   If I do not know the meaning of a word, I look it up in a dictionary.
```

# 重要考点：主将从现

- **与将来有关的时间从句和条件从句，主句使用 will 或 be going to，从句使用一般现在时**

| 主句（will / be going to） | 时间从句（一般现在） |
| :------------------------- | :------------------- |
| Calvin will take a nap | after he finishes his work. |
| Maya is going to read a good book | when she gets home. |
| Those birds will fly south | before the weather becomes too cold. |
| Zack is going to make a phone call | as soon as class is over. |

| 主句（will / be going to） | 条件从句（一般现在） |
| :------------------------- | :------------------- |
| We are going to be late | if we do not leave now. |
| You will do well on the test | if you study hard. |
| People will drive their cars less | if gas becomes very expensive. |

## 注意：主句和从句时态务必准确

```markdown
错误 Eliza will work on her painting when she will have time.
正确 Eliza will work on her painting when she has time.
```
