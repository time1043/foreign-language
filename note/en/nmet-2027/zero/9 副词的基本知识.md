# 副词是什么 What is an Adverb?

- 副词用于**给句子增加更多信息**
- 副词可以**描述动词、形容词和其它副词**
- 副词可以是**一个词**，也可以是**一个介词短语**

```markdown
I _quickly_ **answered** the difficult question. 描述动作
I _very quickly_ answered the difficult question. 描述副词
I very quickly answered the _most difficult_ question. 描述形容词
I very quickly **answered** the most difficult question _in math class_. 介词短语作为副词
```

## 副词有六种：地点、时间、方式、频率、程度、确定性

```markdown
At 5 a.m., my very big cat usually jumps on my bed, and I quickly open my eyes.

_At 5 a.m._, 时间
my _very_ big cat 程度
_usually_ jumps 频率
_on my bed_, 地点
and I _quickly_ open my eyes. 方式
```

每种不同的副词为句子增加不同的信息

|        | 作用                  | 常用词                      |
| :----- | :-------------------- | :-------------------------- |
| 地点   | 增加 Where 的信息     | here, there, in this room   |
| 时间   | 增加 When 的信息      | now, then, in the morning   |
| 方式   | 增加 How 的信息       | quickly, well, carefully    |
| 频率   | 增加 How often 的信息 | always, often, never        |
| 程度   | 增加 How much 的信息  | very, so, extremely         |
| 确定性 | 描述内容的可能性      | certainly, likely, unlikely |

# 1、地点副词和时间副词

- 地点副词增加 Where 的信息
- 时间副词增加 When 的信息

```markdown
My new apartment is _here_, but my old apartment was _near the lake_.
Joe and I watched a movie _last night_. It ended _at 10 p.m_.
```

## 常用词

```markdown
// 常用地点副词和时间副词
地点 here, there, far, somewhere, in, on, at
时间 first, then, next, last; before, after, recently, soon, later, early, finally
```

## 语序位置

```markdown
// 地点副词和时间副词一般出现在句尾
Queen Elizabeth I was born _in London_.
She was born _in 1926_.

// 如果同时出现地点和时间，地点放在时间前面
Queen Elizabeth I was born _in London_ _in 1926_.

// 如果地点或时间短语放在句首，需要用逗号断开
_In France_, people put sugar on their popcorn.
_In 1926_, Queen Elizabeth I was born in London.
// 如果只有一个词的地点或时间，一般不需要逗号断开
_Here_ you can see a map of China.
_Yesterday_ we went to the bank and the post office.
_First_, you should read the text.
```

# 2、方式副词

- 方式副词增加 How 的信息
- 修饰动词

```markdown
You should fry the meat _quickly_ to keep the flavor.
```

## 常用词

```markdown
绝大多数方式副词是形容词加 -ly
个别方式副词是例外情况

| adj.  | adv.  |
| ----- | ----- |
| good  | well  |
| fast  | fast  |
| early | early |
| hard  | hard  |
```

## 语序位置

```markdown
// 方式副词往往放在句尾
Our teacher spoke _clearly_.

// 如果有宾语，方式副词建议放在宾语的后面
He explained the new vocabulary _carefully_.

// 如果动词有两部分，方式副词可以放在中间
I **can** _easily_ **read** this foreign language.
```

# 3、频率副词

- 频率副词增加 How often 的信息
- 修饰动词

```markdown
Kevin and I _never_ eat lunch at noon. Our lunch is _always_ at 11:30 a.m.
```

## 常用词

```markdown
// 常用频率副词
always, usually, often, sometimes, seldom, rarely, never, // 100% - 0%
daily, weekly, monthly, yearly
```

## 语序位置

```markdown
// 频率副词一般放在 be 动词后，其它动词前
I **am** _always_ late to meetings.
I _always_ **arrive** late to meetings.

// 如果动词有两部分，频率副词一般放在中间（和上面一脉相承）
I **can** _usually_ **eat** a whole pizza.
People **should** _always_ **lock** their doors.

// 频率副词 sometimes 可以出现在句首、句中或句尾
_Sometimes_ John and I **watch** TV at night.
John and I _sometimes_ **watch** TV at night.
John and I **watch** TV at night _sometimes_.
```

## 练习：使用频率副词造句回答问题

```markdown
What is something that you always do on Mondays?

What do you usually eat for breakfast?

What is something that you never eat for breakfast?

What is something that you seldom do during the week?

What is something that your mother sometimes does on the weekends?
```

```markdown
What is something that you _always_ do on Mondays?
I _always_ **have** math class on Mondays.

What do you _usually_ eat for breakfast?
I _usually_ **eat** eggs and salads for breakfast.

What is something that you _never_ eat for breakfast?
I _never_ **eat** rice for breakfast.

What is something that you _seldom_ do during the week?
I _seldom_ **get up** late during the week.

What is something that your mother _sometimes_ does on the weekends?
My mother _sometimes_ **does** some cleaning on the weekends.
```

# 4、程度副词

- 程度副词增加 How much 的信息
- 修饰形容词副词

```markdown
The bus station was _very_ crowded. It was _extremely_ hot.
```

## 常用词

```
// 常用程度副词（用于强调）
completely, incredibly, exactly, extremely, really, hardly, barely, nearly, mainly, almost, only, just, quite, so, very, too

// 程度副词 too 是负面含义
The soup was too salty. ✅
The soup was too delicious. 🙅
```

## 语序位置

```markdown
// 程度副词可以用在形容词或副词前
The test was _extremely difficult_.
She sings _very well_.
```

# 5、确定性副词

- 确定性副词描述内容的可能性

```markdown
_Maybe_ he is right about this decision.
```

## 常用词

```
// 常用确定性副词
maybe, perhaps, likely, possibly, probably, clearly, obviously, certainly, definitely
```

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=5355.3&p=9
- 掌握一些常用的词

## 语序位置

```markdown
// 确定性副词一般放在be动词后，其它动词前
The long-term effects of eating salty food **are** _clearly_ harmful.
The Maya people _likely_ **disappeared** due to a disaster.

// maybe, perhaps, clearly, obviously 也可以放在句首
```

## 常见错误

```markdown
In the early summer of 2010 my father got a new job in London.
She speaks well English and French.
I do always my homework.
This play is too wonderful.
```

```markdown
In the early summer of 2010, my father got a new job in London. 时间地点副词放句首需要逗号断开
She speaks English and French _well_. 方式副词一般放在句尾，有宾语放在宾语后面
I _always_ do my homework. 频率副词放在be动词后，其它动词前
This play is _very_ wonderful. 程度副词too是负态度，不描述正面词汇
```
