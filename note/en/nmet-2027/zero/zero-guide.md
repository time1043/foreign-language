# 关于词汇

## 核心词汇最重要

- 老师不能和帮你**背单词**
- 老师能帮你**背的有重点有主次**（背 1000 个考 1000 个）

- 民间说法 3500
- 官方说法 3000 +- 200
- 词汇量够用？外国人词汇够多了考试也只能 120

|      | 类别         | 说明                                           |
| :--- | :----------- | :--------------------------------------------- |
| 2050 | **核心词汇** | 高考各类题目的高频考点，必须掌握准确含义和用法 |
| 700  | 基础词汇     | 初中词汇非高考主要考点，及格线以下同学查缺补漏 |
| 370  | 拓展词汇     | 较难词汇可用于提升实力，目标高分的同学自主选择 |

- 及格线以上只靠背单词提升成绩效果并不理想
- 重点在于通过题目训练掌握解题思路巩固词汇

## 考察要求

- https://www.bilibili.com/video/BV12dGnzUEFN?t=2957.9
- 高考英语以考察认知理解为主
- 记忆目标就是**看英文认识中文**（任务太复杂**做不完** 个数没有意义 遍数没有意义）
- 通过重点考查词义可判断词性
- 通过实际解题过程可积累用法
- 通过各类词汇软件可了解读音
- 尽可能地**减少死记硬背**的内容

## 记忆原则

1. **简答**
2. **熟悉**
3. **重复**

- Relic 遗物 遗址
- Chrysanthemum 菊花
- Strategy 战略 策略

## 记忆方法

- https://www.bilibili.com/video/BV12dGnzUEFN?t=3662.9
- 为什么你不需要艾宾浩斯记忆法？如何记忆语文诗词

1. 第 1 遍，通读手册勾画不认识的词汇，三个小时内完成
2. 第 2-n 遍，**正常阅读**主动记忆，**以周为单位**重复手册（epoch 短期多次重复）

- 你不可能一遍就记住所有单词
- 也不可能以匀速状态记忆单词
- 几个月看不完一遍是无效学习
- 疲劳难受恶心了**再坚持半小时**
- **记忆就是短期多次重复的结果**
