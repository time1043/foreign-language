# 句子必然有动词

- 英语句子的基本要求
- 一组词，有完整意思，有主语，有动词，大写字母开头，句号问号叹号结尾

```markdown
没有主语的句子：祈使句（主语省略）
Stop smoking / Don't speak.

没有动词的句子：交际口语（只能传递最基本的含义）
Good-bye / Hello!
```

- 如果要表达正式的含义，句子必然有**动词**。
- 只要有动词，必然有**时态**。

# 动词最基本的时态：一般现在时

- 狭义现在：当前的一瞬间（现在进行时）
- 广义现在：不分过去现在将来（一般现在时）

- 一般现在时的作用
- 发生过多次的动作 actions that happen **many times**
- 一直都这样的动作 actions that are **always** true

```markdown
红楼梦的作者**是**曹雪芹 // 过去是 现在是 将来还是
曹雪芹*在1742年*写了红楼梦 // 过去的时间
```

# 英语中最基本的动词：Be 动词 " 是 "

## 1 Be 动词一般现在时的三种形态

- 动词为主语服务
- you 可以表示 " 你 " 或 " 你们 "

| 主语            | be 动词肯定  | be 动词否定 | 其他内容      |
| :-------------- | :----------- | :---------- | :------------ |
| I               | **am** 特殊  | **am not**  | from Beijing. |
| He / She / It   | **is** 单数  | **is not**  | in the room.  |
| We / You / They | **are** 复数 | **are not** | hard-working. |

## 2 Be 动词的缩写形式

- 认识即可，建议不要使用
- 缩写格式在正式写作中禁止使用

| 原形     | 缩写    |
| :------- | :------ |
| I am     | I'm     |
| he is    | he's    |
| she is   | she's   |
| it is    | it's    |
| we are   | we're   |
| you are  | you're  |
| they are | they're |

| 原形                | 缩写               |                 |
| :------------------ | :----------------- | --------------- |
| I am not            | I'm not            | am not 不能缩写 |
| he/she/it is not    | he/she/it isn't    |                 |
| we/you/they are not | we/you/they aren't |                 |

## Be 动词和主语的单复数保持一致（非常重要）

- Be 动词为主语服务，必须和主语保持**单复数一致**

```markdown
A book **is** our friend.
Books **are** our friends.

A book **is** on the shelf.
Books **are** on the shelf.

A book **is** necessary.
Books **are** necessary.

Tom **is** a student.
Tom and Kate **are** students.
```

- **动名词**的主语视作单数，但两个或以上动名词词并列时为复数

```markdown
Reading a book **is** necessary. 动名词视作单数
Reading books **is** necessary.

Reading a book **and** writing a paper **are** necessary.
Swimming **and** climbing **are** healthy.
```

## 3 Be 动词的常见句型

| 句型                                 | 句型                    |
| :----------------------------------- | :---------------------- |
| I **am** a student.                  | be 动词 + 名词          |
| I **am** smart.                      | be 动词 + 形容词        |
| I **am** a smart student.            | be 动词 + 形容词 + 名词 |
| You **are** in California.           | be 动词 + 地点短语      |
| My meeting **is** at eleven o'clock. | be 动词 + 时间短语      |

- 常见错误
- **缺谓语** Mary a good person. → Mary **is** a good person.
- **与主语不一致** The boys is in the kitchen. → The boys **are** in the kitchen.
- **否定形式不正确** That computer no is expensive. (Chinglish) → That computer **is not** expensive.

# 介词短语：表达时间和地点

## 介词短语

- 一组词，以**介词** in / on / at 等开始，包括一个**名词或代词**
- 这个名词或代词叫做介词的**宾语**

## 表示地点的介词短语（place / location）

- 回答 where 的问题，一般放在**句尾**

- We **eat** a lot of salad _at home_.
- The computer **is** _on the desk_.
- Loretta **lives** _in my house_.

## 表示时间的介词短语（time）

- 回答 when 的问题，一般放在**句尾**
- 如果与地点短语同时使用时，**时间一般放在地点后面**

- Michele **reads** the newspaper _in the morning_.
- She **sees** him _at the bank_ _on Mondays_.

## 不需要介词的 时间短语和时间短语

- 语言习惯
- Eric **watches** TV _daily_.
- Marco **works** _every afternoon_.

## 如果地点短语或时间短语放在句首，则要用逗号断开

- _In the spring_, everyone **has** finals.
- _Today_, we **have** an important meeting.
- _Twice a week_, Teresa **volunteers** at the library.

## 常见的地点和时间短语

| 地点介词短语   | 时间介词短语   | 时间词和时间短语   |
| :------------- | :------------- | :----------------- |
| at school      | at 9:00 a.m.   | today              |
| at the bank    | at noon        | now                |
| on the wall    | at night       | every day          |
| on Main Street | in the morning | once a week        |
| in the bag     | on Saturdays   | twice a month      |
| in Beijing     | on October 14  | three times a year |

# 常规动词的一般现在时

## 1 常规动词的一般现在时形态

| 主语                | do 形态                  | 例句                                            |
| :------------------ | :----------------------- | :---------------------------------------------- |
| I / You / We / They | 原形                     | come from Beijing / make coffee / work a lot    |
| He / She / It       | 原形 +s **第三人称单数** | comes from Beijing / makes coffee / works a lot |

### 练习：找出句子里的主语和动词

- I **have** busy Mondays.
- _My day_ **begins** very early.
- I **take** a shower at 6 a.m.
- I **eat** breakfast.
- _My friend_ **arrives** at 7 a.m.
- _She_ **drives** me to school.
- We **have** our first class together.
- I **have** five classes on Mondays.
- I also **have** a language club meeting after school.
- _My mother_ **drives** me home at the end of the day.

## 2 第三人称单数动词的特殊变化

### 1）`s / x / sh / ch / z` 结尾的动词，加 `es`

| 原形  | 第三人称单数 |
| :---- | :----------- |
| pass  | passes       |
| wash  | washes       |
| watch | watches      |
| mix   | mixes        |
| fix   | fixes        |

### 2）辅音 + `y` 结尾的动词，去 `y` 改 `i` 加 `es`

| 原形  | 第三人称单数 |
| :---- | :----------- |
| cry   | cries        |
| try   | tries        |
| bury  | buries       |
| marry | marries      |

| 原形 | 第三人称单数 |
| :--- | :----------- |
| play | plays        |
| say  | says         |
| buy  | buys         |

### 3）不规则变化的动词

| 原形 | 第三人称单数 |
| :--- | :----------- |
| have | has          |
| do   | does         |
| go   | goes         |

### 常见错误

```markdown
Ed and Linda in Texas.
Ed work in a big office.
Ed is wakes up at 6 a.m. every day.
Ed try to sleep seven hours every night.
```

```markdown
Ed and Linda **live** in Texas. // 缺谓语
Ed **works** in a big office. // 第三人称单数错误
Ed **wakes up** at 6 a.m. every day. // 多个动词混用
Ed **tries** to sleep seven hours every night. // 第三人称单数错误
```

- 如果使用 be 动词或常规动词的一般现在时，不允许同时出现**两个一般现在时的动词连用**

## 3 常规动词一般现在时的否定表述

- 一般现在时变否定，原来的动词前面加入**助动词 do not/does not**，原来的动词使用**原形 do**

| 主语                | 否定形态     | 例句                                                  |
| :------------------ | :----------- | :---------------------------------------------------- |
| I / You / We / They | **do not**   | **have** a car. <br>**run**. <br>**go** to bed early. |
| He / She / It       | **does not** |                                                       |

- do not 可以缩写为 don't
- does not 可以缩写为 doesn't
- 不建议在正式写作里使用

### 练习：肯定句变为否定句

```markdown
I have a car.
We go to bed early.
He has a book.
She goes to school at 7 am every day.
```

```markdown
I **do not have** a car.
We **do not go** to bed early.
He **does not have** a book.
She **does not go** to school at 7 am every day.
```
