# 字母

- 构成英语的基本单位
- **书写**清楚、整齐非常重要

# 词汇

- 总词汇量约 99 万
- 其中常用词汇量 8 万至 11 万
- 日常生活用语 2000 词左右

- SAT、GRE 要求考生掌握 12000 词以上
- CET4 要求约 4000 词，CET6 约 6000 词
- 高考英语要求考生掌握约 3000 词，其中**核心词汇 2050** 个

# 语法

## 词性

- 共 10 种基本词性
- 前 6 种需要重点掌握

| 词性       | 缩写     | 说明                                                   |
| :--------- | :------- | :----------------------------------------------------- |
| **名词**   | **n.**   | 表示**人或事物**的名称的词                             |
| **动词**   | **v.**   | 表示**动作或状态**的词                                 |
| **形容词** | **adj.** | 表示==人或事物==的**特征**的词                         |
| **副词**   | **adv.** | **修饰**动词、形容词、其他副词或整个句子的词           |
| 连词       | conj.    | 连接单词、短语、从句或句子的词                         |
| 介词       | prep.    | 表示==名词或代词==**与其他词关系的词**                 |
| 代词       | pron.    | **代替**==名词或名词短语==，用来指代某人或某物的词     |
| 冠词       | art.     | 与名词连用，**明确**==名词==所指范围、数量或特定性的词 |
| ~~数词~~   | ~~num.~~ | 表示数量和顺序的词                                     |
| ~~感叹词~~ | ~~int.~~ | 表示说话人感情或语气的词                               |

- 名词 动词 形容词 副词（传递实际意思）
- 连词（内容逻辑关系）
- 介词（全错都扣不了几分）
- 冠词（体现语言习惯）

## 中英差异

- 翻译考题
- 英文有但中文无 作为考点

| 语法点               | 示例                       |
| :------------------- | :------------------------- |
| 所有格 -'s           | He is Fred's best friend.  |
| 动词第三人称单数 -s  | Fred works.                |
| 过去时 -ed           | Fred worked.               |
| 现在分词/进行时 -ing | Fred is working.           |
| 过去分词 -ed         | The car was damaged.       |
| 动名词 -ing          | Working is good for us.    |
| 复数 -s              | Fred has two blue pens.    |
| 比较级 -er           | Fred is smarter than Rick. |
| 最高级 -est          | Fred has the fastest car.  |
