# 什么是代词 What is a Pronoun?

- 代词是替代名词、短语或句子的词（名词性）

```markdown
I live in _China_. _She_ is a great country. // 替代名词
There are _a lot of beautiful flowers_ in the garden. _Some_ are white, and _some_ are red. // 替代短语
_We should respect the elders_. I knew _that_ from my childhood. // 替代句子
```

## 考查重点：主语、宾语（前两列）

```markdown
_I_ **look** at the teacher. The teacher **looks** at _me_.
_You_ **like** cats. Cats **like** _you_.
_He_ **does not like** cats. Cats **do not like** _him_.
_He_ **hears** the cat. The cat **hears** _her_.
_It_ **sees** a dog. The dog **sees** _it_.
_We_ **see** the animals. The animals **see** _us_.
_They_ **wave** at the bus. The bus **stops** for _them_.
```

- 主语在动词的前面
- 宾语可以在动词后面，也可以在介词后面

## 注意事项

1. I 在任何情况下都要大写
2. She 可以指代国家、城市或船舶，表达特殊情感
3. We 可以拉近读者与说话者的距离表示亲近
4. It 可以指代天气、环境、时间，还可以用于**形式主语、形式宾语和强调句型**

```markdown
_It_ is a lovely day.
_It_ is 5 p.m.
```

## 自己：对自己做动作，或强调本人（第三列）

- 自己永远做宾语，如果用在主语需要同位语

```markdown
_I_ am teaching _myself_ computer.
(_You_) Take good care of _yourself_.

_The child_ _himself_ drew this picture.

You should ask _the children_ _themselves_.
```

- “我自己写的”
- ~~Myself wrote this.~~ 不能自己独立出来当主语
- _I_ _myself_ wrote this. 只能作为同位语，表示强调
- _I_ wrote this.

```markdown
同位语 表示强调（逗号方便阅读句子结构）
Mr. Tao, my English teacher, is a man.
This Wednesday, Auguest 3rd, is my birthday.
```

## 某人的，某人的东西（最后两列）

```markdown
I love _my_ country. // 形容词
Is this _your_ car? // 形容词

That car is _mine_ (my car), not _yours_ (your car). // 名词（写全了太啰嗦了）
These books are _ours_ (our books). // 名词
Whose bag is it? It's _hers_ (her bag). // 名词
Yesterday I met a friend of _mine_ (my friends) in the street. // 名词
```

## 常见错误

```markdown
Maria is my friend. He is nice.
Where are my keys? I can't find it.
My mother she is 42 years old.
Myself drive the car.
You should be proud of you.
May I use your pen? Your works better.
We should learn us own culture.
```

```markdown
_Maria_ is my friend. _She_ is nice. // 代词性别要搞清
Where are _my_ keys? I can't find _them_. // 代词单复数搞错
_My mother_ is 42 years old. // 代词主语冲突
_I_ _myself_ drive the car. // 自己不能做主语
_You_ should be proud of _yourself_. // 未使用反身代词
May I use your pen? _Yours_ works better. // 未使用某人的东西
_We_ should learn _our_ own culture. // 未使用形容词性
```

## 练习：找出句中的代词，并分析主语和宾语

```markdown
My name is Robert. I am from Boston.
My sister calls me Bob. She likes Bob better than Robert.
She really likes the name Bob. I do not like it very much.
My sister is a teacher. She has 28 students now. She teaches math to them.
They like her. She is a very good teacher.
```

```markdown
My name is Robert. _I_ am from Boston. 主语
My sister calls _me_ Bob. _She_ likes Bob better than Robert. 宾语 主语
_She_ really likes the name Bob. _I_ do not like _it_ very much. 主语 主语 宾语
My sister is a teacher. _She_ has 28 students now. _She_ teaches math to _them_. 主语 主语 宾语
_They_ like _her_. _She_ is a very good teacher. 主语 宾语 主语
```

## 练习：选择正确的代词

```markdown
(I / Me) live with Joe. (He / Him) is nice. It is easy to live with (he / him).
(I / Me) don't like tests. (They / Them) are very difficult for (I / me).
The blue whale is a big animal. (He / She / It) is the biggest animal on Earth.
Cell phones are very useful. (We / Us) can use (they / them) for many things. For example, (we / us) can call people, take pictures, and send messages with (they / them).
Most people in South America speak Spanish. People in Brazil do not speak Spanish. (He / They) speak Portuguese. (He / She / It) is not the same as Spanish. (It / They) are different languages.
```

```markdown
_I_ live with Joe. _He_ is nice. It is easy to live with _him_.
_I_ don't like tests. _They_ are very difficult for _me_.
The blue whale is a big animal. _It_ is the biggest animal on Earth.
Cell phones are very useful. _We_ can use _them_ for many things. For example, _we_ can call people, take pictures, and send messages with _them_.
Most people in South America speak Spanish. People in Brazil do not speak Spanish. _They_ speak Portuguese. _It_ is not the same as Spanish. _They_ are different languages.
```

# 指示代词

- 表示时间或空间上的远近关系

| 单数 | 复数  | 功能             |
| ---- | ----- | ---------------- |
| this | these | 距离近、后文内容 |
| that | those | 距离远、前文内容 |

## 表示距离远近

```markdown
This is a book. 近
These are cars. 近

I **am** busy _these_ days. 近
I **was** busy _those_ days. 远

That is not a room. 远
Those are trees. 远
```

## 指代前后文内容

```markdown
Please remember _this_: no pain, no gain. 后文
I got up late. _That_ is why I missed the bus. 前文
```

## `one / that / it` 的区别（重要考点）

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=3993.8&p=5

|      |      |                                            |
| :--- | :--- | :----------------------------------------- |
| one  | 模糊 | **泛指**前面提到事物**范围中某一个**       |
| that | 明确 | **特指**前面提到事物中**同类的另一个**     |
| it   | 明确 | **特指**前面提到的事物，**与前面完全相同** |

```markdown
I can't find _my hat_. I think I must buy _one_. 范围中的某一个
_This hat_ is bigger than _that_ of mine. 同类中的另一个
I can't find _my hat_. I don't know where I put _it_. 完全相同

Do you have _that book_? I want to buy _one_. 范围中的某一个
_This book_ is better than _that_ on the shelf. 同类中的另一个
I bought _a book_ yesterday. _It_ is interesting. 完全相同
```

# 疑问代词、连接代词（从句）

- 针对名词内容进行提问的，叫做疑问代词
- 替代名词内容并连接两个分句的，叫做连接代词

| 疑问代词 |            | 疑问副词 |          |
| :------- | :--------- | :------- | :------- |
| who/whom | 提问人     | when     | 提问时间 |
| what     | 提问物     | where    | 提问地点 |
| whose    | 提问归属   | why      | 提问原因 |
| which    | 提问哪一个 | how      | 提问状态 |

## Whom 宾格可以用 Who 代替，介词后面只用 Whom

```markdown
_Who_ is here just now? 主语
_Who_/_Whom_ are you looking for? 宾语
To _whom_ did you speak on the campus? 介词后
```

## Whose 表示 “谁的”

```markdown
_Whose_ are these books on the desk?
_Whose_ books are these on the desk?
```

## What 没有指定范围，which 需要指定范围

```markdown
_What_ book do you like?
_Which_ book do you like, _this one or that one_?
```

## 疑问代词可以连接两个分句，其它代词不可以连接分句

```markdown
_What_ we should do is still unknown. 从句
I know _who_ is waiting for you. 从句

I met many people in my trip, each of _whom_ was nice to me. 两个分句
I met many people in my trip. Each of _them_ was nice to me. 两个独立分句
```

## 疑问词 +ever 表示 “无论”，用于加强语气

- whatever 无论是什么 / whoever 无论是谁 / whichever 无论哪一个
- whenever 无论何时 / wherever 无论何地 / however 无论如何

```markdown
He does _whatever_ she asks him to do.
I'll give the ticket to _whoever_ wants it.
_Whichever_ team gains the most points wins.
```

# 不定代词

- 不明确指代特定名词的，叫做不定代词

```markdown
_Everybody_ should be here in time tomorrow.
I know _nothing_ about it.
That's _all_ I know.
```

## 基本不定代词

|        |        |                                          |
| :----- | :----- | :--------------------------------------- |
| some-  | -body  | somebody, anybody, nobody, everybody     |
| any-   | -one   | someone, anyone, no one, everyone        |
| no-    | -thing | something, anything, nothing, everything |
| every- |        |                                          |

## 其它不定代词 `all, none, both, neither`

|      |          |         |          |
| :--- | :------- | :------ | :------- |
| all  | 所有肯定 | none    | 所有否定 |
| both | 两者肯定 | neither | 两者否定 |

```markdown
_All_ **goes** well. 单独抽象概念单数
_All_ the students **are** here. 具体的名词是复数

_None_ of the milk **is** expensive. 不可数名词用单数
_None_ of the films **is/are** is worth seeing. 可数名词单复数均可

_Both_ of us **can speak** English. 两个人
_Neither_ of us **can sing**. 两个人

_Both_ Jessy _and_ David **are** good at English. 两者都……
_Neither_ you _nor_ he **can finish** the work in an hour. 既不……也不……
```

## 其它不定代词 `few, a few, little, a little, many, much`

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=6154.8&p=5
- 只需要区分肯定否定，永远不要试图区分数量的多少

|       |              |          |                |
| ----- | ------------ | -------- | -------------- |
| few   | 可数**否定** | little   | 不可数**否定** |
| a few | 可数肯定     | a little | 不可数肯定     |
| many  | 可数许多     | much     | 不可数许多     |

```markdown
_Few_ of the books are cheap now. 否定
_A few_ friends came to see me yesterday. 肯定

There is _little_ water in the bottle. 否定
I have _a little_ money to buy the book. 肯定

I have _many_ books to give you.
We have _much_ to say about verbs.
_Many_ of the students like English very much.
_Much_ of the work is easy.
```

## 其它不定代词 `some, any, each, either`

|      |                      |        |                             |
| :--- | :------------------- | :----- | :-------------------------- |
| some | 一些（肯定句）；某个 | any    | 一些（否定句/疑问句）；任何 |
| each | 多者的每一个         | either | 两者中任 一个               |

```markdown
I have _some_ books. 一些 肯定句
Do you have _any_ books? 一些 疑问句
There isn't _any_ ink in my pen. 一些 否定句
I am going to get _some_ ink. 一些 肯定句

You can come _any_ time. 任何
Will you have _some_ coffee? 某个

She gave _each_ child two apples.
_Each_ of us must take responsibility for our own actions.
_Either_ of them will agree to this arrangement. 两者
_Either_ of the two boys **is** clever. 两者
```

## 其它不定代词 `another, the other, others, the others`

|         |                   |            |                 |
| :------ | :---------------- | :--------- | :-------------- |
| another | 另一个 **不确定** | the other  | 另一个 **确定** |
| others  | 其它 不确定       | the others | 其它 确定       |

```markdown
This glass is broken. I want _another_. 不确定 泛指
There are two glasses. One is full. _The other_ is empty. 确定 特指

Some believe it is true. _Others_ doubt it.
There are 40 students in my class. 28 are boys. _The others_ are girls.
```

## 其它不定代词 `each other, one another`

- each other / one another 互相

```markdown
People should love _one another_.
People of different cultures always copy _each other_.
```
