## 练习：找出句子里的名词

- https://www.bilibili.com/video/BV1MY4y1P7Jj?t=880.8&p=2
- 口语考试
- 基本的日常生活表达

- 括号内的数字是句中名词数量的提示

```markdown
What is your favorite food? (1)
This is an excellent question. (1)
My favorite food for breakfast is a sandwich with eggs. (4)
My favorite food for lunch is salad. (3)
My favorite food for dinner is chicken with lemons and red peppers. (5)
My favorite food for dessert is chocolate. (3)
Chocolate is the best food. (2)
I eat chocolate every day. (2)
```

```markdown
What is your _favorite_ **food**? (1) // 形容词 修饰名词
This is an _excellent_ **question**. (1) // 留下足够的思考时间 说话逻辑 早中晚餐

My favorite **food**
_for_ **breakfast**
==is==
a **sandwich**
_with_ **eggs**. (4)
// 介词 表示名词与其他词的关系
// 冠词 对名词的限制作用

My favorite **food** for **lunch** is **salad**. (3)
My favorite **food** for **dinner** is **chicken** with **lemons** and red **peppers**. (5)
My favorite **food** for **dessert** is **chocolate**. (3)

// dessert 甜点
// desert 沙漠

**Chocolate** is the best **food**. (2)
I eat **chocolate** every **day**. (2)
```

# 名词的单复数（重要考点）

- 单数指一个
- 复数指两个或多个

| 单数       | 复数          | 规则                       |
| :--------- | :------------ | :------------------------- |
| an animal  | three animals | 多数名词直接 +s            |
| an address | two addresses | ch/sh/s/x 结尾 +es         |
| a baby     | five babies   | 辅音 +y 结尾，变 y 为 i+es |
| a day      | ten days      | 元音 +y 结尾，直接 +s      |
| a leaf     | four leaves   | f 或 fe 结尾，变 f 为 v+es |

# 可数名词与不可数名词（普通考点）

- 可数名词可以变复数形式
- 不可数名词没有复数形式，只有单数形式

| 可数名词                                | 不可数名词 |
| :-------------------------------------- | :--------- |
| a test, two tests                       | homework   |
| a chair, three chairs                   | furniture  |
| a piece of bread, a few pieces of bread | bread      |

1. 不可数名词只用单数，不和 a/an 及数词搭配使用。
2. 不可数名词表示数量时，需要用**量词**。

- a piece of news 一条新闻
- two pieces of bread 两块面包
- three pieces of paper 三张纸
- four glasses of milk 四杯牛奶
- five bottles of water 五瓶水
- six cups of tea 六杯茶

## 练习：改正句子中名词的错误

- 在写作中会犯同样的错误

```markdown
Two week have fourteen day.
Some young child have problems with their tooth.
We have one teachers for two hour every morning.
Some peoples prefer to do their homeworks late at night.
How many day are there in a years?
```

```markdown
Two **weeks** have fourteen **days**.
Some young **children** have **problems** with their **teeth**.
We have one **teacher** for two **hours** every **morning**. // every one
Some **people** prefer to do their **homework** late at night.
How many **days** are there in a **year**?

// people 人 单复数同形
// peoples 民族（基本用不到）
```

# 专有名词的书写规则

- 专有名词指特定的人名、事物或地点的名字
- 单个词汇的专有名词**首字母必须大写**
- 多个单词构成的专有名词**每个单词的首字母都要大写**
- 专有名词不加冠词

| 名词      | 专有名词                             |
| :-------- | :----------------------------------- |
| a city    | Beijing, Shanghai, New York, Tokyo   |
| names     | Dr. Brown, Mr. Nelson, Michael James |
| time      | Monday, Tuesday, March, August       |
| languages | Chinese, English, Japanese, Korean   |

- 演讲比赛主题 our lovely planet - Our Lovely Planet

# 冠词：对名词进行限制

## 三种冠词

1. 不定冠词 a/an
2. 定冠词 the
3. 零冠词 /

## 单数名词必须要限制词 📏

- **单数名词**禁止裸奔，**必须加限制词**

```markdown
Teacher is nice. ❌
Money is great. ✅
```

## 限制词的种类

1. 冠词 a table / the table
2. 指示代词 this table / that table / these tables
3. 物主代词 my table / your table / his table
4. 数量词 one table / two tables
5. 冠词 + 形容词 a red table / a wooden table

## 不可数名词不一定要限制词 📏

- **复数名词**和**不可数名词**可以使用 the，不加 a/an，**不一定**要加限制词
- (the) money / some money / a lot of money / much money / little money

## 不定冠词 a/an

- 不确定，某一个
- 描述泛指（general）的概念

```markdown
**a man** 某一个人（不知道到底是谁，任何一个人）
I want to see **a movie** this weekend. 看电影（不确定看那部，看哪部都可以）
```

## 元音前用 an，辅音前用 a

- 元音/元音字母：a e i o; u h
- 需要特别注意的词：u 和 h 开头的词

|               |
| :------------ |
| an arthouse   |
| an Englishman |
| an island     |
| an orange     |

|                     |                          |
| :------------------ | ------------------------ |
| **a** university    | /ju:/ 字母 U 读音 - 辅音 |
| **a** unique person |                          |
| **a** utopia        |                          |
| an umbrella         | 啊读音 - 元音            |
| an uncle            |                          |

|               |          |
| :------------ | -------- |
| **a** half    | h 发音   |
| an hour       | h 不发音 |
| an honest boy |          |

## 定冠词 the

- 确定，这个/那个
- 描述具体 （specific） 的概念

```markdown
**the man** 这个人、那个人（很明确的那个人，唯一的那个人）
I want to see **the movie** this weekend. 看那部电影（非常确定的那一部）
```
