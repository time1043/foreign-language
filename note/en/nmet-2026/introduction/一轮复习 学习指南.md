# 一轮复习 学习指南

## 客观题

- 客观题 有**标准答案**（_正确率_ _解题速度_）
- 非客观题 没有标准答案

- ~~讲方法~~一点意义都没有
- 需要学会的是**面对具体内容的分析**

- 面向高三学生（`高一=高三+两年`）
- 宗旨是帮助各位**有效地完成** **减少死记硬背**
- 内部编排顺序：语法 -> 完型 -> 阅读
- 建议从简单到复杂

## 语法填空 36=10+26

- 有提示词

1. 名词复数、代词形式转换
2. 形容词副词比较级最高级
3. 动词时态语态、非谓语动词
4. 名动形副词性转换

- 无提示词

1. 从句关系词、逻辑连词
2. 冠词、介词

## 完形填空 36=1..36

- **句子分析**而不是感觉
- 四种词的**关系**

1. 名词 <-> 动词
2. 名词 <-> 形容词
3. 动词 <-> 副词
4. 形容词 <- 副词 （修饰限定）

5. 名词：相关内容、具体性质
6. 动词：逻辑关系、动词主语、动词对象、具体状态
7. 形容词：事务性质、人物特点、情感态度
8. 副词：动作状态、情感态度、语句标志

## 阅读理解

- 阅读理解 AB

1. 基础不能错
2. 考察的不算是英语，而是对英文字母的认知
3. 对基础的查缺补漏

- 阅读理解 CD

1. 全对且快速
2. 8 道题 16-20 分
3. 15min
4. 越是复杂 套路感越强
5. 标准文章 看到开头就猜到结尾

## 应用文阅读 51

1. 广告：吸引读者完成产品**购买**行为
2. 指南：提供读者所需的**帮助与指导**

## 记叙文文阅读 60

1. 记述事件：通过**单一事件**讲述**道理感悟**
2. 塑造人物：通过**多个经历**塑造**人物形象**

## 说明文阅读 48

1. 针对事实：介绍**事物现象概念**的相关特点
2. 针对研究：介绍**调查研究**的**结论过程意义**

## 议论文阅读 33

1. 行为导向：教育读者采纳正确的**行为建议**
2. 意识导向：通过大量事例**引起读者的重视**

## 七选五 36

- 相邻句关键信息对应

1. 相邻句的**名词**具体内容相关
2. 相邻句的**代词**指代对象明确
3. 相邻句的**感情色彩**正负一致
4. 相邻句的**动词时态**搭配合理
5. 相邻句的**连续动作**顺序连贯
6. 相邻句的**逻辑关系**符合要求

- 段首空格考虑总括句或过渡句

# 核心词汇

## 哪些词汇

1. 2050 核心词汇（**高频考点**）
2. 700 基础词汇（初中词汇 阅读更无障碍）
3. 370 扩展词汇（较难词汇 目标高分）

## 记忆的三原则

1. **简单**：3500 - 2050 - 1000
2. **熟悉**：高频考查核心词汇（十套卷子 隔三岔五）
3. **重复**：词汇手册循环遍数（**需要自己干**）

- 你的记忆力没有问题 剩下的就是努力 1035789
- 让学生记忆的内容

1. 作为老师处理得**足够简单**了么
2. 他们**重复遍数**足够多了么
3. 和他们脑中**现有内容**形成关联了么

## 如何重复

- 除了物理理想状态下存在匀速
- 现实中都是加速度
- 制定不切实际的计划是难以坚持的

1. `1` 通读手册勾画不认识的词汇 **三小时**内完成
2. `2-n` 正常阅读主动记忆 以**周**为单位重复手册

## 记忆单词

1. 你不可能~~一遍就记住~~所有单词
2. 也不可能以~~匀速状态~~记忆单词
3. 几个月看不完一遍是~~无效学习~~
4. 疲劳难受恶心了再坚持半小时
5. 记忆就是**短期多次重复**的结果

# 总结

## 要求

1. 所有课程均要求**先做题**再听课
2. 对比错误思路和**正确思路**差异
3. 分析错误原因并继续做题改进
4. 请根据自身时间安排听课强度
5. 一年两考的同学要求效率加倍
6. 高一高二可尽早完成一轮复习
7. **核心词汇**机器重要务必早记忆
